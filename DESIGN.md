# Direction
Internal admin panel. Tenang, padat informasi, tidak dekoratif.

# Source of truth
Semua token (warna, radius, font, spacing, bayangan) diambil dari Dens UI.
Jangan menambah warna atau font di luar token itu.
Primary: Mars Green (#008c8d). Aksen: oranye Hermès, hanya untuk satu aksi
paling penting per layar. Hex oranye diambil dari dokumentasi Dens UI.

# Rules
- Light dan dark mode keduanya wajib rapi.
- Sidebar kiri + topbar. Tabel dan form jadi tokoh utama, bukan kartu hiasan.
- Tidak ada gradient, glow, atau ikon dekoratif tanpa fungsi.
- Teks UI dalam Bahasa Indonesia, singkat, tanpa hype.
